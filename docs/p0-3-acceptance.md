# P0-3 多人手勢同意與實機驗收

[原始階段規劃](test-plan.md)將 P0-3 定為 1–5 人手勢同意，P0-4 接續人物去背與 1920×1080 PNG。P0-3 使用既有攝影機串流，在本機將手勢與當下的人臉位置配對。手勢與時間依本次確認：每個人在自己臉旁連續比讚（Thumb_Up）滿 1 秒。

## 首版判定方式

- 每個人分開計時，可以先後完成。只計入連續辨識到比讚 的取樣區間；短暫漏偵最多保留 0.5 秒進度，漏偵時間不計入。明確辨識為其他手勢或漏偵超時就重新計時。
- 比讚分數門檻為 0.50。依手掌位置配對，單人放寬臉旁範圍，多人時需能唯一歸屬；同時落在兩人的範圍內會提示拉開距離。歸屬僅依影像位置估計，交叉手臂及遮擋仍需實測。
- 已確認者放手後可等待其他人。人數改變、無法明確延續上一幀的位置，或取樣間隔超過 450 毫秒時會重新確認。1–5 人全數確認才顯示「全員已同意」。無人或超過五人時無法完成。
- 確認狀態只留在記憶體中，停止展示即清除。此階段提供同意狀態；原有「拍照動作」仍是角色動畫測試按鈕。
- 使用[官方手勢模型](https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task)，檔案隨網站提供。低效能裝置的辨識速度與五人同框效果待測。

## 實機驗收（待填）

在本機預覽按「開始展示」，確認除錯資訊中的手勢辨識器與人臉偵測器均為「運作中」。每項記錄裝置、瀏覽器、實際人數與結果。

| 場景 | 通過條件 |
|---|---|
| 單人持續比讚 | 未滿一秒為 0/1；有效辨識滿一秒後為 1/1，顯示全員已同意。 |
| 手勢中斷 | 比讚 半秒、放下超過半秒、再比半秒，仍為 0/1。重新持續滿一秒才確認。其他手勢（包括 YA）不計入。 |
| 二至五人 | 分別以 2、3、4、5 人測試，依序比讚；只有最後一人完成後才顯示全員已同意。 |
| 歸屬與鏡像 | 雙手比讚 只計一人；手放在兩張臉中間時不應替另一人取得同意。切換鏡像後重測。 |
| 進出、重啟與超額 | 加入新人或離開時舊同意清除；六人入鏡提示分組；停止再開始回到零。 |
| P0-2 回歸 | V15 左右眼、最大臉平滑追蹤、拍照動畫與三語切換均可使用。 |

單元測試使用合成座標與時間。Chrome 模擬攝影機已驗證雙模型載入及 V15 展示流程；真人辨識準確度與多人驗收仍須以上表確認。

## 2026-11-09 本機實機驗收紀錄

使用者在比讚版本 `ad78609` 回報「測試OK」。依此次單人測試步驟，將「豎起拇指持續 1 秒可完成同意」記為通過。

兩人依序比讚：通過。使用者確認第一人比讚後顯示「1/2」，第二人比讚後才顯示「2/2，全員已同意」。3–5 人依序確認、手勢中斷、鏡像與人員進出仍待實機驗收。
