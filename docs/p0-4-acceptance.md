# P0-4 人物去背與合照 PNG

[階段規劃](test-plan.md)指定人物分割與 1920×1080 PNG；[架構規劃](architecture.md)列出相機靜態影像、人物遮罩、背景及角色圖層。分支起點為 main 的 `6fac309`。

## 首版操作與設計

1. 按「開始展示」。每個人在臉旁比讚滿 1 秒，看到「全員已同意」後按「拍攝合照」。
2. 系統在下一次手勢取樣凍結相機畫面，對同一張影像再次檢查人臉與同意，再使用 MediaPipe Selfie Segmenter 產生前景遮罩。去背在按下拍攝時執行，即時預覽維持原相機畫面。
3. 合成順序為藍米色漸層、去背人物、左下角 V15 小菁鷹目前姿勢。人物等比例完整置中；輸入與 16:9 不同時由背景填滿空間。鏡像只作用於人物。首版以預設漸層作為背景。
4. 在合照預覽下按「下載 PNG」，取得 1920×1080 的 NTUB-1920x1080.png。可再次拍攝，停止展示會清除頁面上的合照。影像只在瀏覽器內合成。

使用[官方 Selfie Multiclass 256×256 float32 v1 模型](https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_multiclass_256x256/float32/1/selfie_multiclass_256x256.tflite)，SHA-256 為 `c6748b1253a99067ef71f7e26ca71096cd449baefa8f101900ea23016507e0e0`。

### 固定椅背與亮窗複測

2026-11-10：使用者提供的預覽與合照顯示，亮窗前的人臉在原始相機畫面已偏暗，深色椅背也出現在合照中。新版使用背景亮度第 85 百分位估算逆光，並提供空景校正。

- 固定相機和椅子，按「記錄空景（選用）」，所有人完整離開畫面。持續未偵測到人臉約 1.5 秒後，按鈕會變成「清除空景」。回到原位比讚、拍攝，對照臉部與肩後椅背。
- 移動相機或椅子、或光線顯著變動後，請清除並重錄。停止展示會釋放空景。衣物與椅子極為相似時，請檢查衣物有無缺口；可清除空景重拍比較。
- Chrome 模擬逆光與固定深色區塊驗證通過：臉部取樣亮度約由 40 提升至 76，空景校正後固定區塊由深灰轉為漸層背景。PNG 為 1920×1080。實際椅背與衣物邊界仍待同位置複拍確認。

2026-11-10 空景已啟用的真人複測：已觀察到「清除空景」與全員同意；成品手背、頸部及衣領有局部缺口。新版以皮膚、頭髮與衣物分類信心約束空景扣除，衣物另參考鄰近區域的變化。16 項單元測試及編譯通過，Chrome 模擬固定深色區塊仍能移除並輸出 1920×1080 PNG。真人同色前景與椅背交界待複測。

2026-11-10 人物保護修正後的單人複拍：截圖顯示已記錄空景並取得 1/1 同意。合照中的拇指、手背、手腕和頸部輪廓大致連續，上一輪明顯的淺色缺口已改善。畫面右側頸肩交界仍有淡色弧形輪廓，條紋衣物外緣局部破碎，臉部陰影偏紅。單人去背畫質保留為部分改善，整體驗收待確認。

### 新場地設定與光線提醒

工作人員第一次到場，按「設定拍攝環境」，站在訪客的位置比讚一秒，按「拍一張試拍照」。檢查兩側臉頰、眼睛及衣領，滿意後按「確認試拍並完成設定」。完成狀態保存在此瀏覽器；試拍照片不寫入本機儲存。之後直接拍攝合照。換場地時，由工作人員按「重新設定場地」。空景仍為選用。

在人臉可辨識時，每約 0.3 秒取樣臉部與周圍畫面亮度。相同狀態持續至少兩秒才更新提示。較暗人臉且周圍有大片亮區時建議避開逆光；臉部與現場都偏暗時建議補正面柔光。一般拍攝只顯示需要調整的光線。手勢同意、模型與相機就緒等既有條件仍適用。

| 現場測試 | 觀察方式 |
|---|---|
| 正面光 | 柔光位於鏡頭附近。站定約三秒，查看光線提示與眼睛清晰度。 |
| 側光 | 移燈至斜側約 45°，比較兩側臉頰。若仍能清楚辨識，可維持「臉部光線可用」；若整張臉明顯偏暗，應出現提醒。 |
| 較暗室內 | 調暗正面光，保持人臉可辨識約三秒。觀察偏暗提醒，確認仍能試拍；恢復柔光後提示應解除。 |

Chrome 已用公開照片模擬上述三種光線及逆光，確認光線狀態、暗光試拍、未記錄空景的普通合照，以及重新整理後可直接拍攝。18 項自動測試及正式版編譯通過。真人與展場實測待回報。
