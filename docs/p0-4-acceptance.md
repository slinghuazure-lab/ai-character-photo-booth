# P0-4 人物去背與合照 PNG

[階段規劃](test-plan.md)指定人物分割與 1920×1080 PNG；[架構規劃](architecture.md)列出相機靜態影像、人物遮罩、背景及角色圖層。分支起點為 main 的 `6fac309`。

## 首版操作與設計

1. 按「開始展示」。每個人在臉旁比讚滿 1 秒，看到「全員已同意」後按「拍攝合照」。
2. 系統在下一次手勢取樣凍結相機畫面，對同一張影像再次檢查人臉與同意，再使用 MediaPipe Selfie Segmenter 產生前景遮罩。去背在按下拍攝時執行，即時預覽維持原相機畫面。
3. 合成順序為藍米色漸層、去背人物、左下角 V15 小菁鷹目前姿勢。人物等比例完整置中；輸入與 16:9 不同時由背景填滿空間。鏡像只作用於人物。首版以預設漸層作為背景。
4. 在合照預覽下按「下載 PNG」，取得 1920×1080 的 NTUB-1920x1080.png。可再次拍攝，停止展示會清除頁面上的合照。影像只在瀏覽器內合成。

使用[官方 Selfie Segmenter float16 v1 模型](https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/1/selfie_segmenter.tflite)，SHA-256 為 `191ac9529ae506ee0beefa6b2c945a172dab9d07d1e802a290a4e4038226658b`。

## 驗收表

| 場景 | 通過條件 | 首版驗證 |
|---|---|---|
| 同意門檻 | 尚未全員同意時無法拍攝；可拍後若拍攝幀不再符合，取消拍攝 | 單人按鈕門檻已用 Chrome 測試；真人進出待驗 |
| 單人去背與角色 | 原背景替換，人物及角色可見，成品無除錯欄或控制按鈕 | 單人比讚測試影像已下載並目視檢查 |
| 畫質與比例 | 人物不變形，髮絲、手指與衣物邊緣可接受，原背景無明顯殘留 | 方形輸入已檢視；真人逆光、移動與複雜背景待驗 |
| 多人同框 | 全員同意後，畫面中每人都完整保留；遮擋及邊緣人物需逐一檢視 | 真人多人待驗 |
| 鏡像與重拍 | 人物方向隨鏡像改變，角色留在左下角；重拍更新合照 | 已比較兩次輸出取樣像素 |
| PNG | 下載檔可解碼且為 1920×1080 PNG，不受攝影機原始尺寸影響 | Chrome 實際下載、檢查 PNG 檔頭與尺寸、解碼預覽 |
| 停止與錯誤 | 停止後清除預覽；分割模型失敗時相機仍可用，解除問題後能重新載入 | 已在 Chrome 驗證 |
| 行動裝置 | 手機直向與橫向皆能拍攝、查看並儲存橫式成品 | iOS／Android 待驗 |

2026-11-10：分支正式版編譯及既有 12 項自動測試通過。上述 Chrome 測試使用本機網站與公開比讚影像作為模擬攝影機來源。
