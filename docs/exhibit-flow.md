# 展覽模式與工作人員驗收

啟動攝影機後，預設進入訪客展示。桌面、平板和手機使用同一個舞台；工作人員可展開「展場設定」調整鏡頭、語言、動畫、試拍及空景。試拍模式與訪客循環分開。

| 階段 | 操作與驗收 |
|---|---|
| 待機 | 畫面以小菁鷹為主。從三個設定的待機動畫中選一個開始，每連續待機五分鐘輪換一次。 |
| 問好 | 有人臉進入後播放 Hello。首版使用模型的站立動作加手臂揮動；可改指定其他動作。 |
| 邀請 | 同一條位置追蹤累積 3 秒後，詢問是否合照。邀請顯示滿 10 秒仍無人比讚同意，就回到待機；持續在場的同一批人不會立刻再次收到邀請。邀請期間並提示比讚後照片會上傳。短暫全畫面漏偵最多保留 0.75 秒進度，空檔不計時。人臉離開或位置配對不明，不能將不同人的停留時間相加。 |
| 拍攝 | 一個以上在臉旁且能明確歸屬的讚啟動預覽。顯示鏡頭及角色，從三個設定動作隨機選一個。開始五秒倒數時鎖定同一畫面中比讚的人。倒數期間可放手，僅追蹤原有人物，後來入鏡或比讚的人等下一輪。 |
| 快門 | 倒數顯示至 1，五秒到時取下一個可用攝影幀並發出快門聲。已比讚者離開後，以仍在畫面內且可確認身分的參與者完成原倒數。若無人符合則取消本次拍攝。 |
| 去背與分享 | 以姿勢關鍵點將人物與前景連通區配對，取比讚者所屬區域的聯集，再與既有人像去背結果及 V15 角色合成。本機產生 1920×1080 PNG；正式模式自動上傳私人儲存區，模擬模式僅傳至本機。人數統計為入選人數。 |
| QR | QR 產生後才開始十秒掃碼倒數，到時自動清除畫面中的合照與 QR，回到待機。已掃到的限時連結仍可用。 |

### 動畫設定

展開「展場設定 → 角色動畫設定」。待機及拍照各選三個不同動作，問好選一個；設定保存在這台展示機的瀏覽器。預設待機為閱讀踢腳、思考、站立張望；拍照為跳舞、比愛心、比 YA。

### 展場條件

人臉停留時間來自短期位置追蹤，沒有建立臉部辨識資料庫。流程允許單人及多位清楚可分辨的人物加入。多人時姿勢偵測容量依當下臉數調整，實際可辨識人數取決於鏡頭視野、距離與裝置效能。若人臉、姿勢與遮罩無法一對一配對，或人物明顯重疊，保留已比讚者並提示站開，五秒後自動重拍一次。仍無法分開時取消本次合照，顯示回到待機按鈕。校正或重新開始展示後重新計時。側身、被遮住、局部入鏡的人可能漏偵；逆光、路人穿越與擁擠場景應在展場另行驗證。上傳失敗提供本機下載及回待機入口。

姿勢關鍵點採 [MediaPipe Pose Landmarker Lite](https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task)，於拍攝幀在瀏覽器內執行。

### 開發分支驗證（2026-11-10）

Chrome 使用模擬攝影機驗證單人、兩人同框僅一人加入、三人同框左右兩人加入。三人測試核對 QR 取得的 PNG 為 1920×1080，中間未比讚者位置呈現替換背景，拍攝紀錄為 2 人。雙人另外已在本機雲端版驗證 Supabase 自動上傳、以未登入連線取回下載及 QR 顯示後回待機。瀏覽器測得角色設定共七個選項、重新整理後保存，以測試時鐘核對五分鐘輪換；375 像素寬度無水平溢出。單元測試含不可分離的人物前景必須中止輸出。實際展場最大可辨人數、現場是否聽得清楚快門聲、擁擠與逆光下的去背畫質仍待確認。

### 匯入自訂角色

在「展場設定 → 角色動畫設定」選「匯入 GLB 角色」。使用自含網格、材質及動畫的 GLB 2.0 檔案。七個選單會顯示檔案實際的動畫片段，依序指定三個待機、一個問好、三個拍照動作；動作數較少時可重複使用。匯入檔和指派存在此展示機瀏覽器，重新整理後可繼續使用。可按「還原內建小菁鷹」切回 V15。自訂模型的 Hello 使用選定片段；內建 V15 的預設 Hello 使用程式揮手。

單人驗收：工作人員試拍完成後，按「結束試拍，回到展示」。Hello 會顯示合照邀請的剩餘秒數。3 秒後出現「一起合照嗎？」才舉起拇指。
